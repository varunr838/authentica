# smart-contracts — Authentica Phase 2

> **On-Chain Proof Verification & Video Registry**
> Deploy the EZKL-generated verifier and a permanent authenticity ledger to Ethereum (Sepolia testnet).

---

## Architecture

```
[ proof_generator.py ]  →  proof.json + instances[]
          │
          │  (Backend submits on-chain)
          ▼
  VideoRegistry.publishVideo(videoHash, proof, instances)
          │
          ├──► IVerifier.verify(proof, instances)
          │         │
          │         └──► BN254 elliptic curve pairing (in real EZKL contract)
          │                   │
          │                   └── true / false
          │
          ├──► (if false) → revert InvalidProof()
          │
          └──► (if true)  → store VideoRecord on-chain
                            emit VideoVerified(videoHash, publisher, proofDigest, …)
```

## Contracts

| Contract | Description |
|---|---|
| `Verifier.sol` | **Auto-generated by EZKL.** Replace with `zkml-engine/artifacts/verifier.sol`. Contains BN254 pairing math. |
| `VideoRegistry.sol` | Custom registry. Calls Verifier, stores records, emits events. |
| `MockVerifier.sol` | Test-only. Returns configurable true/false. |

## Quick Start

### Prerequisites

- Node.js ≥ 18
- An Alchemy / Infura RPC key for Sepolia
- A funded Sepolia wallet (get ETH from https://sepoliafaucet.com)
- (For production) The real `verifier.sol` from Phase 1's `zk_compiler.py`

### 1. Install

```bash
cd smart-contracts
npm install
```

### 2. Configure environment

```bash
cp .env.example .env
# Edit .env and fill in PRIVATE_KEY, SEPOLIA_RPC_URL, ETHERSCAN_API_KEY
```

### 3. (Recommended) Copy the real EZKL verifier

```bash
# After running Phase 1's zk_compiler.py:
cp ../zkml-engine/artifacts/verifier.sol contracts/Verifier.sol
```

> If you skip this, the stub verifier is deployed. It compiles and deploys
> correctly but `verify()` always returns `false`.

### 4. Compile

```bash
npm run compile
```

### 5. Run tests

```bash
npm test
```

### 6. Deploy locally

```bash
# Terminal 1 — start local node
npm run node

# Terminal 2 — deploy
npm run deploy:local
```

### 7. Deploy to Sepolia

```bash
npm run deploy:sepolia
```

Deployment addresses are saved to `deployments/sepolia.json`.

### 8. Verify on Etherscan

```bash
npx hardhat verify --network sepolia <VERIFIER_ADDRESS>
npx hardhat verify --network sepolia <REGISTRY_ADDRESS> "<VERIFIER_ADDRESS>"
```

## Contract API

### `VideoRegistry`

#### `publishVideo(bytes32 videoHash, bytes proof, uint256[] instances)`
Submit a zk-SNARK proof. Calls Verifier, stores record, emits `VideoVerified`.

| Parameter | Description |
|---|---|
| `videoHash` | SHA-256 (as bytes32) of the blurred output video |
| `proof` | Serialised proof bytes from `proof_generator.py` → `proof.json` |
| `instances` | Public circuit outputs (quantised model logits) |

Reverts with:
- `InvalidProof()` — zk-SNARK verification failed
- `VideoAlreadyRegistered(bytes32)` — duplicate hash
- `ZeroHash()` — videoHash is zero
- `EmptyProof()` — proof bytes are empty

#### `isVerified(bytes32 videoHash) → bool`
Returns `true` if the video has been registered with a valid proof.

#### `getRecord(bytes32 videoHash) → VideoRecord`
Returns the full on-chain record including publisher, timestamp, and instances.

#### Events
```solidity
event VideoVerified(
    bytes32 indexed videoHash,
    address indexed publisher,
    bytes32         proofDigest,
    uint64          timestamp,
    uint256[]       instances
);
```

## Gas Estimates

| Operation | Estimated Gas |
|---|---|
| Deploy Verifier (stub) | ~200 000 |
| Deploy Verifier (real EZKL) | ~3 000 000 |
| Deploy VideoRegistry | ~800 000 |
| `publishVideo` (per call) | ~650 000 (dominated by BN254 pairing) |
| `isVerified` | ~2 500 (view) |

> Real EZKL verifiers are large contracts (~24 KB). `viaIR: true` is set
> in hardhat.config.js to avoid the contract size limit.
